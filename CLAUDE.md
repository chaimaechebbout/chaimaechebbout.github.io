# Chaimae Chebbout — portfolio site

Static personal portfolio, hosted on GitHub Pages. No build step, no framework.

- `index.html` — the live site (served at the root of GitHub Pages).
- This version leaves out the Master's degree on purpose. Do not add it back.

## Design rules
- Palette: Tyrian purple #66023C, Citron #CAD183, moss #4F5B1F, rose #E7C3CC / #9C4C64, paper #F6F5EC. All colours are CSS variables in the `:root` block at the top of each file; edit them there.
- Fonts come from Google Fonts (Instrument Serif / Fraunces / Cormorant Garamond for display; a grotesk for body).
- Keep light and dark themes working (the `prefers-color-scheme: dark` blocks).
- Must work at phone width (~400px) with no horizontal scroll.

## Content rules (important)
- Never name clients or brands (no McDonald's, Coca-Cola, Pepsi, CAMH, Nike, Converse, Tommy Hilfiger, Mango, Urban Jungle). Use "international brands" / "national client accounts".
- Do not add a phone number.
- Tone: consulting language, strong and concrete; positioning is project & product management grounded in business analytics.
- Do not invent metrics. Ask Chaimae before adding any number.
- She writes her own copy: propose wording, don't rewrite whole sections without asking.
